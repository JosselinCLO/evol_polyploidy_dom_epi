# evol_polyploidy_dom_epi
Data and code for the pre-publication "The contribution of non-additive genetic effects to the genetic variance of polyploid species."

* The Rcode allow to perform numerical iterations of the theoretical model developed in the manuscript, for different genetic architectures.
* The dataset is made of estimates of additive variance (raw or narrow-sense heritabilities) and non-additive components of genetic diversity (dominance variance standardized over phenotypic variance, epistatic variance standardized over phenotypic variance, or broad-sense heritability). Those estimates come from the agronomic literature. The species names, family, ploidy level, and origin, in addition to the reference from which the estimate comes.
